### Coding Standards

The aim of these standards: the code must be clean, easy to read and easy to mantain.

Use explicit variable names. Put descriptive and explicit comments on important parts of the code, or on parts of the code that are hard to understand on first read. Use proper typing for variables and methods. 

### Tool use
If you are not sure or don't have the context for a particular bit of information (let's say I ask about a very particular thing from a certain library of package), use the web search tools.
